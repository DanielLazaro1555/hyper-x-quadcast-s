# Modelo 3D del QuadCast S

Guarda aquí el archivo GLB descargado de Sketchfab con este nombre:

`quadcast-s.glb`

El visor lo carga desde `/models/quadcast-s.glb`. La escena conserva el modelo procedural de respaldo si el archivo aún no está instalado.
